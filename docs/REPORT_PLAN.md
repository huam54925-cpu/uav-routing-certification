## 核心论断草稿

在原论文问题一 Case1 的后续研究中，采用带连通性割的有向边流松弛及精确对偶证书，建立三机不可行性的距离下界，并在 Lean 4 中形式化验证路线到约束的推理、弱对偶、距离比较、工作时间预算及具体证书数值。证明进一步排除所有少于四架的参与机队。结合独立 Python 验证的四机可行路线，确定指定数学模型下的最小机队规模为四架。四机可行性尚未纳入 Lean，四机最大工作时间的全局最优性仍未证明。
