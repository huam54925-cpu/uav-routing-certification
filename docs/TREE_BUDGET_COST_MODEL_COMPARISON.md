## 参数化结论的前提

若同一个明确的完整执行器已证明
`Time ≤ K S³(M+1)(ell+1)^d`，其中 `K,d` 与输入、参数无关，则已有
`S≤2^M`、`S≤(U+1)^t`、`M≤tU` 给出

* `Time ≤ K 2^(3M)(M+1)(ell+1)^d`；
* `Time ≤ K (U+1)^(3t)(tU+1)(ell+1)^d`。

这才支持所选模型下的 FPT(`M`) 和 FPT(`t,U`)。
单独的事件计数界、原语上界或假设总时间界的代数引理不能替代该前提。
标准图灵机分类还须说明模拟；也不能把参考模型的时间直接称为 Lean 编译程序的实测时间。

若重数使用一元编码，令完整输入长度为 `N`，则 `U,M≤N`，上述界给出
`K(N+1)^(3t+d+1)`，属于关于 `t` 的 XP 形式。
二进制编码没有 `U≤ell`，故不能沿用此推导。

## 显式输出的边界

取根和一个非根顶点的树，非根重数为 `m`、费用和预算为零。
每个合法单次根出发行必须使用该唯一边一次，成功矩阵恰有 `m` 行；
此时 `t=1`，输入重数仅需 `O(log(m+1))` 位，逐行序列化至少要写 `m` 个记录。
这是二进制输入下显式矩阵输出的长度障碍，不是否定判定问题属于 XP(`t`) 的证明。
它也没有给出仅树高、树宽或车辆数的分类。压缩矩阵、实际顶点路线展开和需求到 `H`
的包装器是另外的计算任务，不能从当前输出协议自动继承时间界。
