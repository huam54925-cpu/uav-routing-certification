# Working rules

Read [docs/REPOSITORY_POLICY.md](docs/REPOSITORY_POLICY.md) before committing or publishing.

- This repository is `huam54925-cpu/uav-routing-certification`. Verify the destination before pushing.
- Stage explicit paths, review the staged diff, and use ordinary commits and non-forced pushes.
- Keep logs, raw run output, chat/API dumps, downloaded dependencies, credentials and build products local under ignored `verification/runs/`.
- Preserve the thirteen frozen Lean modules, their data and dependency pins unless a proof change is explicitly requested. Historical checks are not new checks.
- Distinguish the original paper, the repeated-visit correction, the formal lower bound, and the independently checked four-UAV witness.
- Commit/push when requested, using authorization already given. Publication here does not authorize other repositories, remote branch deletion, history rewriting, visibility changes or maintainer contact.
